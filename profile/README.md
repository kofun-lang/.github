# Kofun

An experimental programming language with a bootstrap written in Kofun and
direct ELF64 backends for x86-64 and AArch64. Source files use `.kofun`.

[Language site](https://kofun-lang.github.io/kofun/) ·
[Compiler](https://github.com/kofun-lang/kofun) ·
[Releases](https://github.com/kofun-lang/kofun/releases)

## Where things are

| Repository | What it holds |
| --- | --- |
| [kofun](https://github.com/kofun-lang/kofun) | The language: compiler, bootstrap, and backends |
| [kofun-pm](https://github.com/kofun-lang/kofun-pm) | Package manager: minimal version selection, a content-addressed store, digest-pinned locks, and no install scripts |
| [kofun-boot](https://github.com/kofun-lang/kofun-boot) | Application framework: typed contracts, capability injection, deterministic replay |
| [kofun-auth](https://github.com/kofun-lang/kofun-auth) | OAuth 2.1, OpenID Connect, JWT, sessions, and TOTP |
| [haniwa](https://github.com/kofun-lang/haniwa) | Desktop app shell: system webview, host-side WebRTC, small binaries |
| [kofun-site](https://github.com/kofun-lang/kofun-site) | The official site, docs renderer, and playground |
